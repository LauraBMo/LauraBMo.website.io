** NEXT [#A] Attach laurabmo.com to the Worker                       :domain:
Sidebar *Workers & Pages* (newer dashboards: *Compute (Workers)*) → the =laurabmo=
Worker → *Settings* → *Domains & Routes* → *Add* → *Custom Domain* → =laurabmo.com=.

* Decisions
:PROPERTIES:
:CREATED:  [2026-08-04]
:END:

| Decision              | Chose                    | Over                          | Because                                          |
|-----------------------+--------------------------+-------------------------------+--------------------------------------------------|
| LaTeX                 | build-time KaTeX         | runtime KaTeX, MathJax        | no runtime JS, no CDN, no flash of raw source     |
| Fonts                 | self-hosted woff2        | Google Fonts                  | GDPR — Munich court, 2022                        |
| Analytics             | Cloudflare Web Analytics | none, GA, zone analytics only | cookieless, per-path, bot-filtered, no new party  |
| Beacon                | in-repo partial          | Cloudflare edge injection     | what ships to visitors stays visible in the repo  |
| Host                  | Cloudflare Workers       | GitHub Pages, Cloudflare Pages | Pages is being folded into Workers; no dashboard setup |
| Build                 | GitHub Actions           | Cloudflare build system       | keeps version pin and --panicOnWarning in repo    |
| Domain                | laurabmo.com             | .xyz, .me, .cat               | neutral for job search, email deliverability      |
| Registrar             | Cloudflare               | keep separate                 | user preference; note the concentration risk      |
| Local toolchain       | native Hugo (dnf)        | Docker, Podman                | static binary; containers bought nothing          |
| Hugo version          | pinned, 0.162.1          | latest                        | breakage arrives when you choose, not at random   |
